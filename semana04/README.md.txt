# Semana 04 - Clasificador de Lluvia para Huancayo con Redes Neuronales

Este proyecto implementa una red neuronal multicapa (MLP) utilizando **TensorFlow/Keras** para clasificar si un día será lluvioso o no en Huancayo, a partir de datos climáticos de temperatura máxima, mínima y amplitud térmica.
